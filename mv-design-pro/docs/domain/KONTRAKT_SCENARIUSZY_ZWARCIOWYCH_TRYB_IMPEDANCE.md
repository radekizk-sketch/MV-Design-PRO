## 2. Fizyka (rdzeń IEC 60909, addytywnie)
- Parametr Z_f = R_f + jX_f wchodzi addytywnie do `compute_equivalent_impedance` i czterech metod `compute_*_short_circuit` (`exclude_none`): 3F: Z_1 + Z_f; 2F: Z_1 + Z_2 + Z_f; 1F: Z_1 + Z_2 + Z_0 + 3·Z_f; 2FE: Z_1 + Z_2·(Z_0 + 3·Z_f)/(Z_2 + Z_0 + 3·Z_f) (3·Z_f w torze składowej zerowej) — wzory jawne w White Box (krok „Z_f” + pętla z podstawieniem) i w `EquationRegistry` (LaTeX: EQ_SC1_013 1F–Z, EQ_SC1_014 2F, EQ_SC1_015 2F–Z, EQ_SC1_016 prądy składowe z pętli). Wynik z Z_f niesie dodatkowo (addytywnie, `exclude_none`): `z_f_ohm`, impedancję pętli przy Z_f = 0 (`zkk_metaliczne_ohm`), prąd zwarcia metalicznego tego punktu i `poza_zakresem_iec60909 = true`.
- Twierdzenie sanity-bound dla pętli SZEREGOWYCH (3F, 2F, 1F): przy R_f ≥ 0, X_f ≥ 0 i impedancji pętli w pierwszej ćwiartce zachodzi |Z + k·Z_f|² = |Z|² + k²|Z_f|² + 2k·Re(Z·conj(Z_f)) ≥ |Z|², więc |I_k(Z_f)| ≤ |I_k(0)| jest własnością algebraiczną — test iloczynu ją przypina. **Korekta karty (partia 10):** dla 2F+G (pętla z gałęzią RÓWNOLEGŁĄ Z_2 ‖ (Z_0 + 3Z_f)) ta nierówność NIE jest własnością algebraiczną — przypięty kontrprzykład (Z_0 rezystancyjna, Z_f indukcyjna) daje prąd przez Z_f WIĘKSZY niż metaliczny; ślad White Box niesie wtedy oba prądy i nie twierdzi spełnienia warunku (`tests/network_model/solvers/test_zwarcie_przez_impedancje_przejscia.py`).
- i_p (κ) i I_th dla Z_f ≠ 0 liczone tymi samymi wzorami IEC 60909 z R/X pełnej pętli (z Z_f) — wartości poglądowe, zablokowane jako podstawa wytrzymałości przez SI-117 (§3).

## 3. Zakres ważności i proweniencja (werdykt wyjaśnialny)
- Wynik z Z_f ≠ 0 dostaje w proweniencji `poza_zakresem_iec60909 = true` (norma definiuje prąd zwarciowy dla zwarcia metalicznego).
- Warstwa autorytetu (`network_model/core/zdolnosci_wkladu_zwarciowego.py`, kod **SI-117** `KOD_BLOKADY_IMPEDANCJA_ZWARCIA`, O-66) **blokuje** wynik z Z_f ≠ 0 dla zdolności `ZDOLNOSCI_BLOKOWANE_PRZY_IMPEDANCJI_ZWARCIA`: PROTECTION, BREAKING_CAPACITY_SELECTION, PROTECTION_COORDINATION, SC_WITHSTAND_EVIDENCE, REGULATORY_EVIDENCE, ARC_FLASH — dobór i wytrzymałość aparatury, pakiet Equipment, nastawy nadprądowe i koordynacja, dowód regulacyjny w punkcie przyłączenia (S''_k, SCR, migotanie, wniosek OSD) i energia łuku. Konsumenci biegu odmawiają kodem SI-117 z polem `dane.zdolnosc` (API 422), a selekcja „najnowszego biegu zwarciowego” (werdykt projektowy, generatory) pomija bieg przez Z_f. **Dozwolone**: SHORT_CIRCUIT_3F/1F (prezentacja wyniku) i EARTH_FAULT_SETTINGS (nastawy zabezpieczeń doziemnych — prądy minimalne) — wpisane jawnie w tej samej liście autorytetu, nie jako wyjątek w konsumencie. **Stan konsumenta doziemnego:** w repo nie ma silnika nastaw 50N/51N, który czytałby wynik biegu zwarciowego (`build_earthing_ground_fault_input` nie ma wywołującego produkcyjnego) — zdolność EARTH_FAULT_SETTINGS jest dopuszczona w autorytecie, ale nie ma dziś konsumenta; jego budowa należy do domeny zabezpieczeń doziemnych, nie do tej karty.
- Prezentacja: Z_f zapisana na biegu (`konfiguracja_biegu.impedancja_przejscia`, wyłącznie Z_f ≠ 0) jako wiersz sekcji ZAŁOŻENIA ekranu `ui2/wyniki/zwarcia` z uwagą o zakresie ważności; wkłady źródeł punktu liczone z tą samą Z_f; krok Z_f w dowodzie SC3F i w dowodach SC1 (1F–Z, 2F, 2F–Z).
