## (b) False-verdict risks (verdict without simulation, or tautological)

1. **Live on the user path:** `frt_trajektorie.py:82` / `frt_sekwencja` give "w obwiedni" for a 3 s sag to 0.06 pu and for 60 s at 1.25 pu (P3). The criterion is v > 0.05 applied to an input voltage profile — a tautology.
2. **Legacy DYNAMIC_STABILITY:** the verdict comes from user-typed rotor angles; the UI shows a synthetic U(t)/f(t); `automation_trace` states "Fault cleared by protection path" with no protection involved.
3. **PTPiREE settings checks read as compliance:** T01/T03 (LFSM) PASS on a settings comparison (`engine.py:440-510`); T17 PASS on a declared K_FRT ≥ K_min (`:923-980`); T16 PASS on a supplied recovery time (`:885-921`). Today the ENM bridge feeds None (`S/application/ncrfg_compliance/model_bridge.py:245-246`), so T16/T17 come out as `no_data`. Any future feed from `frt_hvrt` would reintroduce the tautology.
4. **Limiter:** \|I\| overshoot of up to +7 % (P1) would make any `current_limit_behavior` criterion wrong. The pinning test is blind because of its Tp/Tiq ratio.
5. **SO-1A:** trajectories after 1.18 s describe a clearing that is physically impossible for this topology, yet SO-1A is used as the acceptance reference.
6. **Frequency fallback value:** an unavailable f is published as 50.0 Hz. Any metric or criterion that ignores `jakosc_f` gets exactly the fallback the owner forbade. No mutation or test guards consumers.
7. **Metrics on the output grid only:** `u_min` / `t_u_min` are taken on a 20 ms grid in SO-1A, so minima between samples are missed and time-in-band criteria can pass falsely.
8. **`delta_max_rad`:** an absolute angle, so it drifts with frequency and gives a false "instability" in islands. It is not a stability criterion.
9. **GFL-only island:** physics impossibility is reported as numerical non-convergence (P2); the user is told "the solver failed" instead of "no grid-forming source".
10. **PV at under-frequency:** raises P above available power (S_n window), which reads as fake support.
11. **stay_connected from the device model:** the GFL never trips, so it would always be true.
12. **Id/Iq swap:** in the PLL frame d = reactive, q = active; a criterion labelled "I_d active" would read the wrong axis.
